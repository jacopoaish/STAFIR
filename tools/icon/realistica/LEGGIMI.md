# Icona "Bussola dei ricordi" (versione realistica)

- `bussola.html` + `render_bussola.js`: bussola 3D (three.js) in titanio, oro, 7 diamanti taglio brillante e
  zaffiro stellato di Ceylon sulla ghiera a est; illuminazione HDRI "studio_small_08" (Poly Haven, CC0),
  texture metallo Metal009 / Metal012 (ambientCG, CC0).
- `componi_icona.js`: composizione finale (sfondo, nebulose, foto a spirale, scia nebulosa).
- Le immagini sorgenti non sono nel repository (sono grandi): vedi crediti sotto.
- `anteprima-1024.png`: anteprima dell'icona.
